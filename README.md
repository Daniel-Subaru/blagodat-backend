# ✝ Небесна Крамниця — Шаблонний магазин

Структура файлів для VS Code:

```
bible-store/
├── index.html          ← Головна сторінка
├── css/
│   └── style.css       ← Усі стилі + теми + анімації
├── js/
│   └── script.js       ← Кошик, фільтри, тема, анімації
└── assets/             ← Папка для ваших зображень
```

---

## 🎨 Теми

- **Світла** — бежевий/рожевий фон (#f7f0eb)
- **Темна** — світло-сірий (#2b2b2b)
- Перемикач у navbar (праворуч). Тема зберігається в localStorage.

---

## ➕ Як додати категорію

1. У `index.html` знайди блок `<!-- ТУТ МОЖНА ДОДАВАТИ НОВІ КАТЕГОРІЇ -->`
2. Скопіюй і розкоментуй шаблон:

```html
<button class="cat-card" data-category="my_cat">
  <div class="cat-card__icon">🆕</div>
  <h3 class="cat-card__name">Назва</h3>
  <p class="cat-card__count" data-cat-count="my_cat">0 товарів</p>
  <div class="cat-card__glow"></div>
</button>
```

3. Додай кнопку фільтру у `.filter-bar`:

```html
<button class="filter-btn" data-filter="my_cat">Назва</button>
```

---

## ➕ Як додати товар

Знайди блок `<!-- ТУТ МОЖНА ДОДАВАТИ НОВІ ТОВАРИ -->` і скопіюй будь-яку картку:

```html
<div class="product-card" data-category="my_cat" data-id="99" data-price="500">
  <div class="product-card__img-wrap">
    <div class="product-card__img" style="background:#d4c5a5;">
      <span class="product-card__emoji">🎁</span>
    </div>
    <div class="product-card__overlay">
      <button class="product-card__quick">Швидкий перегляд</button>
    </div>
  </div>
  <div class="product-card__body">
    <p class="product-card__cat">Назва категорії</p>
    <h3 class="product-card__name">Назва товару</h3>
    <div class="product-card__stars">★★★★★</div>
    <div class="product-card__footer">
      <span class="product-card__price">500 ₴</span>
      <button class="product-card__buy btn btn--primary btn--sm" data-id="99">
        🛒 В кошик
      </button>
    </div>
  </div>
</div>
```

**Важливо:** `data-id` має бути унікальним для кожного товару.

---

## 🖼️ Як додати зображення товару

Замість emoji-плейсхолдера:

```html
<div class="product-card__img" style="background:#ccc;">
  <img
    src="assets/my-product.jpg"
    alt="Назва"
    style="width:100%;height:100%;object-fit:cover;"
  />
</div>
```

---

## 📦 Кошик

- Товари зберігаються в `localStorage` — не зникають при перезавантаженні
- Зміна кількості прямо в кошику (+/−)
- Кнопка видалення товару
- Підсумок автоматично перераховується

---

## 🔧 CSS змінні (легке налаштування)

У `css/style.css` на початку файлу є `:root { ... }` і `[data-theme="dark"] { ... }` —
змінюй кольори там без пошуку по всьому файлу.

Головні змінні:
| Змінна | Призначення |
|--------|-------------|
| `--bg-page` | Фон сторінки |
| `--accent` | Акцентний колір (кнопки, заголовки) |
| `--text-primary` | Основний текст |
| `--radius-md` | Заокруглення карток |

# Благодать Крамниця — Оновлення!

## Що зроблено?

### 1. Окремі сторінки для категорій

- Створено окремі HTML-файли для кожної категорії:  
  `bibles.html`, `paintings.html`, `clocks.html`, `books.html`, `games.html`, `cups.html`
- Кожна сторінка має власний набір товарів і систему пошуку.
- Збережено єдиний дизайн, тему (світла/темна) та анімації.

### 2. Система пошуку на сторінках категорій

- Поле пошуку фільтрує товари за назвою або категорією.
- Лічильник «Знайдено: X / Y» і повідомлення «Нічого не знайдено».
- Кнопка очищення пошуку.
- Анімація підсвічування знайдених карток.

### 3. Швидкий перегляд товару (Quick View)

- При натисканні на кнопку «Швидкий перегляд» відкривається модальне вікно.
- У модальному вікні:
  - **Карусель зображень** (стрілки вліво/вправо, точки-індикатори).
  - При натисканні на картинку – **збільшення (zoom)** на весь екран.
  - Поле для **опису** товару (атрибут `data-description`).
  - Категорія, рейтинг, ціна (зі знижкою або без).
  - Кнопка «Додати в кошик».
- Закриття: кнопка `×`, клік на фоні, клавіша `Esc`.
- Гортання фото: стрілки вліво/вправо або клік на точках.

### 4. Автоматичний розрахунок знижок

- Якщо на картці є бейдж `sale -10%` (або -15%, -20% тощо):
  - Стара ціна перекреслюється.
  - Нова ціна відображається червоним кольором.
  - У кошик додається ціна зі знижкою.
- Підтримуються будь-які відсотки.

### 5. Анімації та адаптивність

- Модальне вікно з'являється з ефектом масштабування.
- Карусель і зум працюють плавно.
- Адаптація під мобільні пристрої (модалка займає 95% екрану, кнопки зручні для тапа).

### 6. Збереження оригінального коду

- Файли `index.html`, `style.css`, `script.js` **не змінено**.
- Додаткові стилі (пошук, модальне вікно) дописано в кінець існуючих CSS/JS.
- Окремі файли `category.css` та `category-search.js` — лише для сторінок категорій.

## Як додати власні зображення та опис?

У кожному товарі (`.product-card`) додайте атрибути:

```html
<div
  class="product-card"
  data-id="101"
  data-price="890"
  data-image-1="images/bible1.jpg"
  data-image-2="images/bible1_back.jpg"
  data-image-3="images/bible1_detail.jpg"
  data-description="Шкіряна обкладинка, золоте тиснення, 1200 сторінок."
>
  ...
</div>
```
